# sample-vault

Fictional example data for the dashboard — safe to commit, safe to demo.

Folders:
- `goals/` — what you're aiming at (drives "groom my day")
- `projects/` — projects and learning paths (ordered child tasks)
- `routines/` — recurring tasks (health, review rituals)
- `tasks/` — individual to-dos

Each file is markdown with a small YAML frontmatter block. To use your own data, set
`VAULT_PATH` in `.env` to a different folder.
